# LayoutSwitcher — авто-переключение раскладки по активному окну

Фоновая программа для macOS: запоминает раскладку клавиатуры для каждого
приложения (и окна) и применяет её при смене активного окна.

- Терминал — английский, Telegram — русский, в браузере два окна — разные
  раскладки, и т.д.
- Окна различаются по заголовку (у браузера — по заголовку вкладки), поэтому
  у одного приложения у разных окон может быть своя раскладка.
- Раскладки запоминаются пассивно: когда окно активно и нет ввода,
  текущая раскладка считается выбором пользователя и сохраняется.
  Явно «сказать» программе раскладку не нужно — просто попечатайте.

## Сборка

```sh
cd keyboard-layout-switcher
./build_app.sh          # swiftc + LayoutSwitcher.app
```

Собирается `.app`-бандл `LayoutSwitcher.app` с bundle id
`com.stefania.layoutswitcher` и ad-hoc подписью.

> **Запуск из терминала безопасен:** `./LayoutSwitcher` сам открывает себя
> как `LayoutSwitcher.app` и возвращает терминал (процесс не привязан к нему).
> Делать так обязательно: macOS 26 присваивает TCC-доступ субъекту через
> процесс-ответственного — при прямом запуске бинаря из терминала запрос
> идёт от имени Terminal, и доступ к Специальным возможностям не выдаётся.
> Из `.app` через `open` (или автозапуск) субъект — само приложение.
> Если `.app` рядом с бинарём нет — `./LayoutSwitcher` запустится как обычно.

## Первый запуск

```sh
open LayoutSwitcher.app
```

При первом запуске macOS спросит доступ к **Специальным возможностям**
(System Settings → Privacy & Security → Accessibility). Разрешите — программа
сама перепроверяет доступ и начинает работать без перезапуска.

По возможности разрешите и **Input Monitoring** (тот же экран) — тогда
обучение точнее: программа не «забудет» раскладку во время печати.

## Управление

| Команда | Что делает |
|---|---|
| `open LayoutSwitcher.app` | запуск |
| `./LayoutSwitcher` | запуск (сам открывает себя как .app) |
| `./LayoutSwitcher --install` | автозапуск при входе (LaunchAgent на бинарь внутри .app) |
| `./LayoutSwitcher --quit` | завершить работающий инстанс |
| `./LayoutSwitcher --uninstall` | записать LaunchAgent-файл (для ручного `rm`) |

В меню-баре появляется буква текущей раскладки («Я»/«A») — там же можно
выключить автозапуск и посмотреть текущую раскладку активного окна.

Данные: `~/.layout-switcher/state.json` (можно удалить — «забудет» всё),
лог: `log show --predicate 'subsystem == "com.stefania.layoutswitcher"'`.

## Ограничения / известное поведение

- Смену **вкладки** браузера программа воспринимает как смену окна (заголовок
  окна = заголовок вкладки) — каждому заголовку своя раскладка.
- В терминале заголовок меняется при `cd`: для новых путей применяется
  раскладка приложения, не окна.
- Программа не переключает раскладку принудительно при смене фокуса ввода
  внутри одного окна (например, между текстовыми полями) — только при смене
  активного окна/приложения.
- Если программа «перетягивает» раскладку при быстрых Cmd-Tab — слегка
  увеличьте паузу стабилизации в `tick()` (сейчас 0.3 с / 2 итерации).
